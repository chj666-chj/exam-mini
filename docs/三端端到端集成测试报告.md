## 三、修复详情

### 修复1：新增 `/auth/me/` 端点

**文件**: `backend/adminapi/urls.py`

```python
# 修改前
path('auth/profile/', views_auth.profile, name='admin-profile'),

# 修改后
path('auth/me/', views_auth.profile, name='admin-me'),
path('auth/profile/', views_auth.profile, name='admin-profile'),
```

**影响**: 前端管理后台和外部集成可通过标准 `/auth/me/` 获取当前登录用户信息，无需硬编码 token 解析。

### 修复2：用户管理支持 PATCH 局部更新

**文件**: `backend/adminapi/views_data.py`

```python
# 修改前：user_dispatch 只支持 PUT
if request.method == 'PUT':
    err = _can_manage(request)
    return err or user_update(request, openid)

# 修改后：同时支持 PUT 和 PATCH
if request.method in ('PUT', 'PATCH'):
    err = _can_manage(request)
    return err or user_update(request, openid)
```

同时修改 `user_update` 方法的方法检查：
```python
# 修改前
if request.method != 'PUT':
    return fail(ErrorCode.PARAM_ERROR, '请使用 PUT 提交', http_status=405)

# 修改后
if request.method not in ('PUT', 'PATCH'):
    return fail(ErrorCode.PARAM_ERROR, '请使用 PUT 或 PATCH 提交', http_status=405)
```

**影响**: 管理后台可通过 `PATCH /api/admin/users/<openid>/` 局部更新用户状态（如停用/恢复），无需提交完整用户对象。
