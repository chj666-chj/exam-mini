## 1. 测试概述与系统架构分析

### 1.1 系统架构总览

考试宝系统采用三端架构，覆盖考试全生命周期：

| 层级 | 技术栈 | 端口 | 核心职责 |
|------|--------|------|----------|
| **后端** | Django + SQLite(WAL) | 8000 | REST API、通用文档模型、RBAC鉴权、AI服务层 |
| **管理后台** | Vue3 + Vite + Element Plus + ECharts | 5173 | 题库管理、考试管理、AI配置、数据看板、用户管理 |
| **小程序** | 微信原生小程序 | — | 答题考试、知识库学习、文章阅读、AI辅助、排行榜 |
