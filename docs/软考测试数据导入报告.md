## 三、数据结构设计

### 3.1 集合关系

```
exam (科目)
  ├── RK_RJJS (软件设计师)
  │     ├── subjects (章节) → pid=RK_RJJS
  │     │     ├── RK_RJJS_CH01 (计算机系统基础知识)
  │     │     │     ├── questions (习题) → examid=RK_RJJS_CH01
  │     │     │     │     ├── RK_RJJS_CH01_Q01 (单选, 难度2)
  │     │     │     │     ├── RK_RJJS_CH01_Q02 (单选, 难度2)
  │     │     │     │     ├── RK_RJJS_CH01_Q03 (多选, 难度3, 配图)
  │     │     │     │     ├── RK_RJJS_CH01_Q04 (判断, 难度1)
  │     │     │     │     └── RK_RJJS_CH01_Q05 (单选, 难度2)
  │     │     ├── RK_RJJS_CH02 ~ RK_RJJS_CH06
  │     │     └── ...
  │
  └── RK_XXXT (信息系统项目管理师)
        ├── subjects (章节) → pid=RK_XXXT
        │     ├── RK_XXXT_CH01 ~ RK_XXXT_CH06
        │     └── ...
        └── ...

testcases (测试用例, 独立集合)
  ├── TC_001 ~ TC_005: 习题作答
  ├── TC_006 ~ TC_007: 章节切换
  ├── TC_008 ~ TC_009: 科目切换
  ├── TC_010 ~ TC_011: 题型筛选
  ├── TC_012 ~ TC_013: 答题模式
  ├── TC_014: 配图渲染
  └── TC_015: 边界情况
```

### 3.2 与小程序页面的兼容性

| 小程序页面 | 使用的数据字段 | 数据来源 |
|-----------|--------------|----------|
| entry (题库入口) | subjects.name, questions[examid] | subjects + questions 集合 |
| exam (单题答题) | questions.title, options, qtype | quiz_questions storage |
| simple (列表答题) | questions.title, options | quiz_questions storage |
| question (列表提交) | questions.title, options | quiz_questions storage |
| examresult (结果) | userAnswers vs correct options | quiz_questions storage |
| list (答题详情) | questions, userAnswers | quiz_questions storage |
| score (排名) | historys.rightNum, nums | historys 集合 |
| review/note (错题) | questions, userAnswers | notes/storage |

### 3.3 ID 命名规范

```
RK_{科目缩写}_CH{两位章节号}_Q{两位题号}

RK     → 软考前缀
RJJS   → 软件设计师
XXXT   → 信息系统项目管理师
CH01   → 第一章
Q01    → 第一题

示例: RK_RJJS_CH03_Q02 = 软件设计师-第三章-第二题
```

**验证**: `ast.parse()` 语法检查通过 ✅

## 五、导入命令使用说明

```bash
# 导入软考数据（自动清理旧软考数据，保留原有演示数据）
python manage.py seed_exam_data

# 清空所有集合后导入（含原有演示数据）
python manage.py seed_exam_data --reset

# 追加模式（不清理任何数据）
python manage.py seed_exam_data --append
```

**数据文件**: `backend/core/management/commands/seed_exam_data.py`  
**数据存储**: Django Document 模型 (collection + doc_id + data JSONField)
