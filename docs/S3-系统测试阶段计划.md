## 2. 测试维度

### 2.1 功能测试（API 黑盒 + 文件操作）

| 维度 | 覆盖内容 |
|------|----------|
| 文件上传 | 管理端 `/api/admin/upload/`（需 `question.manage` 权限）+ 小程序端 `/api/upload/`（公开） |
| 文件下载 | Excel 模板下载 `/api/admin/questions/import/templates/<qtype>/` + 媒体文件 `/media/uploads/...` |
| 文件格式校验 | jpg/png/gif/webp/bmp/svg 白名单；非图片格式拒绝 |
| 文件大小校验 | ≤5MB 通过；>5MB 拒绝 |
| 文件列举 | `GET /media/uploads/<month>/` 目录列举；上传后返回 URL 可访问 |
| 文件删除 | 管理端无直接文件删除 API（通过 OS 清理）；验证上传后不残留非法文件 |
| 集合 CRUD | questions/historys/notes/favorites/articles 全链路增删改查 |
| 权限控制 | superadmin/operator/viewer 三角色 × 32 权限点矩阵 |

### 2.2 接口测试

| 维度 | 覆盖内容 |
|------|----------|
| HTTP 方法 | GET/POST/PUT/DELETE/PATCH 各端点方法校验 |
| 状态码 | 200/400/401/403/404/405/500 各场景 |
| 信封一致性 | 管理端 `{code,message,data}` vs 小程序端原生结构 |
| 分页参数 | `page/pageSize` 管理端分页；小程序集合**不支持分页**（易错点） |
| 参数校验 | 必填字段缺失、类型错误、空值、超长字符串 |

### 2.3 异常处理测试

| 维度 | 覆盖内容 |
|------|----------|
| 并发访问 | 10/20/50 并发交卷、并发收藏、并发导入 |
| 安全边界 | SQL 注入、XSS、IDOR、未授权访问、令牌伪造 |
| 数据异常 | 空数组、超大 payload、嵌套 JSON、Unicode/emoji |
| 网络异常 | 超时、连接中断、慢响应 |
| AI 异常 | apiKey 未配置、模型超时、空响应、推理模型 reasoning 兼容 |
