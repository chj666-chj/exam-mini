## 二、数据已导入方式

数据已通过 Django management command 直接写入数据库（`backend/db.sqlite3`），存储在 `core_document` 表中：

- **题目** → `collection='questions'`，`doc_id` 格式：`RK_{学科}_{章节}_Q{类型}{序号}`
  - 类型代码：S=单选, M=多选, J=判断
  - 示例：`RK_RJJS_CH01_QS001`（软件设计师第1章第1道单选题）
  
- **试卷** → `collection='exam'`，`doc_id` 格式：`PAPER_{学科}_{名称}`
  - 示例：`PAPER_RJJS_基础测试卷`

### 生成命令

```bash
# 完整生成（清空旧批量数据 + 生成题库 + 生成试卷）
cd backend
python manage.py seed_batch_questions --clean

# 仅生成题库
python manage.py seed_batch_questions --questions

# 仅生成试卷
python manage.py seed_batch_questions --papers

# 追加模式（不清理已有数据）
python manage.py seed_batch_questions
```

## 四、校验方法

### 1. 数据库直接查询

```bash
cd backend
python -c "
import os, django
os.environ['DJANGO_SETTINGS_MODULE'] = 'backend.settings'
django.setup()
from core.models import Document

# 总题数
print('题目总数:', Document.objects.filter(collection='questions').count())

# 各章节题目数
from django.db.models import Q
for ch in ['RK_RJJS_CH01', 'RK_RJJS_CH02', ...]:
    count = Document.objects.filter(collection='questions', doc_id__startswith=ch+'_Q').count()
    print(f'{ch}: {count}')

# 试卷列表
for p in Document.objects.filter(collection='exam', doc_id__startswith='PAPER_'):
    d = p.to_client()
    print(f'{d[\"name\"]}: {d[\"questionCount\"]}题, 总分{d[\"totalScore\"]}')
"
```

### 3. 重复检测

已在生成时通过 `(examid, title)` 组合去重，校验结果：**0 组重复**。

### 4. 必填字段校验

抽检100道题，所有题目均包含：`title`, `qtype`, `examid`, `answer`, `options` — **0 道缺失**。

### 5. 选项格式校验

抽检100道题：
- 单选题：恰好1个正确选项 ✅
- 多选题：≥1个正确选项 ✅
- 判断题：恰好1个正确选项 ✅
- **0 道异常**

## 五、补充配置说明

### 需要补充的配置项

1. **题型配置**：系统支持6种题型（single/multiple/judge/fill/qa/multi_part），但当前考试仅配置了3种（单选/多选/判断）。如需生成填空题和问答题，需在考试配置中增加 `questionTypes` 条目。

2. **难度标识统一**：
   - 数字 `1` = 入门（Tag: 入门, 颜色: #63b56b）
   - 数字 `2` = 简单（Tag: 简单, 颜色: #97c459）
   - 数字 `3` = 中等（Tag: 中等, 颜色: #f0b34a）
   - 数字 `4` = 困难（Tag: 困难, 颜色: #e8833a）
   - 数字 `5` = 挑战（Tag: 挑战, 颜色: #d9534f）

3. **知识点关联**：生成后可运行 `python manage.py seed_knowledge_points --clean` 重新生成知识点关联。
